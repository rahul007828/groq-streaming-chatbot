# Groq Streaming Chatbot

A Python-based streaming chatbot built using the Groq API.

## Features

- Groq API integration
- Streaming responses
- Conversation history
- Token counting
- Context management
- Conversation summarization
- Token budget
- Input/output token tracking
- API cost estimation

## Technologies

- Python
- Groq API
- tiktoken
- python-dotenv
